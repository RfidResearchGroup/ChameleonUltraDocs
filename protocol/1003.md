# 1003: SET_ACTIVE_SLOT

Set active slot number.

* CLI: cf `hw slot change`

## Request Packet

```mermaid
---
title: "Request Packet"
---
packet
+8: "SOF"
+8: "LRC1"
+16: "CMD (=1003)"
+16: "STATUS"
+16: "LEN (=1)"
+8: "LRC2"
+8: "slot number"
+8: "LRC3"
```

* DATA in Request Packet
    * slot number: `1 byte`, between `0` and `7`.

## Response Packet

```mermaid
---
title: "Response Packet"
---
packet
+8: "SOF"
+8: "LRC1"
+16: "CMD (=1003)"
+16: "STATUS"
+16: "LEN (=0)"
+8: "LRC2"
+8: "LRC3"
```

* DATA in Response Packet: None
