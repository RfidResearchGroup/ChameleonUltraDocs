# 1004: SET_SLOT_TAG_TYPE

Set tag type of specific slot.

* CLI: cf `hw slot type`

## Request Packet

```mermaid
---
title: "Request Packet"
---
packet
+8: "SOF"
+8: "LRC1"
+16: "CMD (=1004)"
+16: "STATUS"
+16: "LEN (=3)"
+8: "LRC2"
+8: "slot number"
+16: "tag type"
+8: "LRC3"
```

* DATA in Request Packet
    * slot number: `1 byte`, between `0` and `7`.
    * tag type: `2 bytes`, U16 in network byte order, according to `tag_specific_type_t` enum.

## Response Packet

```mermaid
---
title: "Response Packet"
---
packet
+8: "SOF"
+8: "LRC1"
+16: "CMD (=1004)"
+16: "STATUS"
+16: "LEN (=0)"
+8: "LRC2"
+8: "LRC3"
```

* DATA in Response Packet: None
