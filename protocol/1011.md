# 1011: GET_DEVICE_CHIP_ID

Get device chip ID.

* CLI: cf `hw chipid`

## Request Packet

```mermaid
---
title: "Request Packet"
---
packet
+8: "SOF"
+8: "LRC1"
+16: "CMD (=1011)"
+16: "STATUS"
+16: "LEN (=0)"
+8: "LRC2"
+8: "LRC3"
```

* DATA in Request Packet: None

## Response Packet

```mermaid
---
title: "Response Packet"
---
packet
+8: "SOF"
+8: "LRC1"
+16: "CMD (=1011)"
+16: "STATUS"
+16: "LEN (=8)"
+8: "LRC2"
+64: "device chip id"
+8: "LRC3"
```

* DATA in Response Packet
    * device chip id: `8 bytes`, U64 in network byte order.
