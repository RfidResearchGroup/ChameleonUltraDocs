# 1012: GET_DEVICE_ADDRESS

Get device BLE address.

* CLI: cf `hw address`

## Request Packet

```mermaid
---
title: "Request Packet"
---
packet
+8: "SOF"
+8: "LRC1"
+16: "CMD (=1012)"
+16: "STATUS"
+16: "LEN (=0)"
+8: "LRC2"
+8: "LRC3"
```

* DATA in Request Packet: None

## Response Packet

```mermaid
---
title: "Response Packet"
---
packet
+8: "SOF"
+8: "LRC1"
+16: "CMD (=1012)"
+16: "STATUS"
+16: "LEN (=6)"
+8: "LRC2"
+48: "bluetooth address"
+8: "LRC3"
```

* DATA in Response Packet
    * bluetooth address: `6 bytes`, U48 in network byte order.
