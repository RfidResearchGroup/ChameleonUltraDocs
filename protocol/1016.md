# 1016: GET_ANIMATION_MODE

Get device power on animation.

* CLI: cf `hw settings animation`

## Request Packet

```mermaid
---
title: "Request Packet"
---
packet
+8: "SOF"
+8: "LRC1"
+16: "CMD (=1016)"
+16: "STATUS"
+16: "LEN (=0)"
+8: "LRC2"
+8: "LRC3"
```

* DATA in Request Packet: None

## Response Packet

```mermaid
---
title: "Response Packet"
---
packet
+8: "SOF"
+8: "LRC1"
+16: "CMD (=1016)"
+16: "STATUS"
+16: "LEN (=1)"
+8: "LRC2"
+8: "current animation mode"
+8: "LRC3"
```

* DATA in Response Packet
    * animation mode: `1 byte`, according to `settings_animation_mode_t` enum.
