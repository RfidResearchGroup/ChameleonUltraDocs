# 1018: GET_ACTIVE_SLOT

Get active slot number.

* CLI: cf `hw slot list`

## Request Packet

```mermaid
---
title: "Request Packet"
---
packet
+8: "SOF"
+8: "LRC1"
+16: "CMD (=1018)"
+16: "STATUS"
+16: "LEN (=0)"
+8: "LRC2"
+8: "LRC3"
```

* DATA in Request Packet: None

## Response Packet

```mermaid
---
title: "Response Packet"
---
packet
+8: "SOF"
+8: "LRC1"
+16: "CMD (=1018)"
+16: "STATUS"
+16: "LEN (=1)"
+8: "LRC2"
+8: "current active slot"
+8: "LRC3"
```

* DATA in Response Packet
    * current active slot: `1 byte`, between `0` and `7`.
