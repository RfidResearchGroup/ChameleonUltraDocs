# 1020: WIPE_FDS

Device factory reset.

The device will reboot shortly after this command.

* CLI: cf `hw factory_reset`

## Request Packet

```mermaid
---
title: "Request Packet"
---
packet
+8: "SOF"
+8: "LRC1"
+16: "CMD (=1020)"
+16: "STATUS"
+16: "LEN (=0)"
+8: "LRC2"
+8: "LRC3"
```

* DATA in Request Packet: None

## Response Packet

```mermaid
---
title: "Response Packet"
---
packet
+8: "SOF"
+8: "LRC1"
+16: "CMD (=1020)"
+16: "STATUS"
+16: "LEN (=0)"
+8: "LRC2"
+8: "LRC3"
```

* STATUS in Response Packet
    * `STATUS_SUCCESS`: Success
    * `STATUS_FLASH_WRITE_FAIL`: Fail
* DATA in Response Packet: None
