# 1029: SET_LONG_BUTTON_PRESS_CONFIG

Set button long press function of specific button.

* CLI: cf `hw settings btnpress`

## Request Packet

```mermaid
---
title: "Request Packet"
---
packet
+8: "SOF"
+8: "LRC1"
+16: "CMD (=1029)"
+16: "STATUS"
+16: "LEN (=2)"
+8: "LRC2"
+8: "button"
+8: "button function"
+8: "LRC3"
```

* DATA in Request Packet
    * button: `1 byte`, Char `'A'`/`'a'`: Button A, Char `'B'`/`'b'`: Button B.
    * button function: `1 byte`, according to `settings_button_function_t` enum.

## Response Packet

```mermaid
---
title: "Response Packet"
---
packet
+8: "SOF"
+8: "LRC1"
+16: "CMD (=1029)"
+16: "STATUS"
+16: "LEN (=0)"
+8: "LRC2"
+8: "LRC3"
```

* DATA in Response Packet: None
