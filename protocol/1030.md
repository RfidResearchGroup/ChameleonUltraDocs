# 1030: SET_BLE_PAIRING_KEY

Set BLE pairing key.

* CLI: cf `hw settings blekey`

## Request Packet

```mermaid
---
title: "Request Packet"
---
packet
+8: "SOF"
+8: "LRC1"
+16: "CMD (=1030)"
+16: "STATUS"
+16: "LEN (=6)"
+8: "LRC2"
+48: "BLE pairing key"
+8: "LRC3"
```

* DATA in Request Packet
    * BLE pairing key: `6 bytes`, ASCII-encoded digits.

## Response Packet

```mermaid
---
title: "Response Packet"
---
packet
+8: "SOF"
+8: "LRC1"
+16: "CMD (=1030)"
+16: "STATUS"
+16: "LEN (=0)"
+8: "LRC2"
+8: "LRC3"
```

* DATA in Response Packet: None
