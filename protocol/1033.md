# 1033: GET_DEVICE_MODEL

Get device type (Ultra/Lite).

* CLI: cf `hw version`

## Request Packet

```mermaid
---
title: "Request Packet"
---
packet
+8: "SOF"
+8: "LRC1"
+16: "CMD (=1033)"
+16: "STATUS"
+16: "LEN (=0)"
+8: "LRC2"
+8: "LRC3"
```

* DATA in Request Packet: None

## Response Packet

```mermaid
---
title: "Response Packet"
---
packet
+8: "SOF"
+8: "LRC1"
+16: "CMD (=1033)"
+16: "STATUS"
+16: "LEN (=1)"
+8: "LRC2"
+8: "device type"
+8: "LRC3"
```

* DATA in Response Packet
    * device type: `1 byte`, according to `chameleon_device_type_t` enum (`0`=Ultra, `1`=Lite)
