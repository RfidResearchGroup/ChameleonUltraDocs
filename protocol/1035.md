# 1035: GET_DEVICE_CAPABILITIES

Get supported command IDs.

## Request Packet

```mermaid
---
title: "Request Packet"
---
packet
+8: "SOF"
+8: "LRC1"
+16: "CMD (=1035)"
+16: "STATUS"
+16: "LEN (=0)"
+8: "LRC2"
+8: "LRC3"
```

* DATA in Request Packet: None

## Response Packet

```mermaid
---
title: "Response Packet"
---
packet
+8: "SOF"
+8: "LRC1"
+16: "CMD (=1035)"
+16: "STATUS"
+16: "LEN (=N*2)"
+8: "LRC2"
+16: "supported commands (variable length)"
+8: "LRC3"
```

* DATA in Response Packet
    * supported commands: `N*2 bytes` in network byte order, a list of supported commands IDs.
