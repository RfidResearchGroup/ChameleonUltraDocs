# 1036: GET_BLE_PAIRING_ENABLE

Get BLE pairing is enabled or not.

* CLI: cf `hw settings blepair`

## Request Packet

```mermaid
---
title: "Request Packet"
---
packet
+8: "SOF"
+8: "LRC1"
+16: "CMD (=1036)"
+16: "STATUS"
+16: "LEN (=0)"
+8: "LRC2"
+8: "LRC3"
```

* DATA in Request Packet: None

## Response Packet

```mermaid
---
title: "Response Packet"
---
packet
+8: "SOF"
+8: "LRC1"
+16: "CMD (=1036)"
+16: "STATUS"
+16: "LEN (=1)"
+8: "LRC2"
+8: "ble pairing isEnabled"
+8: "LRC3"
```

* DATA in Response Packet
    * ble pairing isEnabled: `1 byte`, `0`=disabled, `1`=enabled
