# 3001: EM410X_WRITE_TO_T55XX

Write EM410x ID to T55xx tag.

* CLI: cf `lf em 410x write`

## Request Packet

```mermaid
---
title: "Request Packet"
---
packet
+8: "SOF"
+8: "LRC1"
+16: "CMD (=3001)"
+16: "STATUS"
+16: "LEN (=9+N*4)"
+8: "LRC2"
+40: "em410x_id"
+32: "new_key"
+32: "old_keys (N*4 bytes, N>=1)"
+8: "LRC3"
```

* DATA in Request Packet
    * em410x_id: `5 bytes`, The EM410x tag ID to write to the T55xx tag.
    * new_key: `4 bytes`, The new key to be written to the T55xx tag. The key will also be add to old keys list.
    * old_keys: `N*4 bytes, N>=1`, The old keys to be used for authentication.

## Response Packet

```mermaid
---
title: "Response Packet"
---
packet
+8: "SOF"
+8: "LRC1"
+16: "CMD (=3001)"
+16: "STATUS"
+16: "LEN (=0)"
+8: "LRC2"
+8: "LRC3"
```

* DATA in Response Packet: None
