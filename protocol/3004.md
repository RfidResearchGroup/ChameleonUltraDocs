# 3004: VIKING_SCAN

Scan ID of Viking tags.

## Request Packet

```mermaid
---
title: "Request Packet"
---
packet
+8: "SOF"
+8: "LRC1"
+16: "CMD (=3004)"
+16: "STATUS"
+16: "LEN (=0)"
+8: "LRC2"
+8: "LRC3"
```

* DATA in Request Packet: None

## Response Packet

```mermaid
---
title: "Response Packet"
---
packet
+8: "SOF"
+8: "LRC1"
+16: "CMD (=3004)"
+16: "STATUS"
+16: "LEN (=4)"
+8: "LRC2"
+32: "scanned_id"
+8: "LRC3"
```

* DATA in Response Packet
    * scanned_id: 4 bytes. The Viking tag ID be scanned.
