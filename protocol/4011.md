# 4011: MF1_SET_GEN1A_MODE

Set the Mifare Classic emulator to emulate gen1a magic tag or not.

* CLI: cf `hf mf econfig`

## Request Packet

```mermaid
---
title: "Request Packet"
---
packet
+8: "SOF"
+8: "LRC1"
+16: "CMD (=4011)"
+16: "STATUS"
+16: "LEN (=1)"
+8: "LRC2"
+8: "gen1a_mode"
+8: "LRC3"
```

* DATA in Request Packet
    * gen1a_mode: `1 byte`. Whether to emulate the Gen1A magic tag or not for the actived slot.

## Response Packet

```mermaid
---
title: "Response Packet"
---
packet
+8: "SOF"
+8: "LRC1"
+16: "CMD (=4011)"
+16: "STATUS"
+16: "LEN (=0)"
+8: "LRC2"
+8: "LRC3"
```

* DATA in Response Packet: None
