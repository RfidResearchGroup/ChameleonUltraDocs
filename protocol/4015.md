# 4015: MF1_SET_BLOCK_ANTI_COLL_MODE

Set the toggle whether to use anti-collision data from emulator block 0 or not.

* CLI: cf `hf mf econfig`

## Request Packet

```mermaid
---
title: "Request Packet"
---
packet
+8: "SOF"
+8: "LRC1"
+16: "CMD (=4015)"
+16: "STATUS"
+16: "LEN (=1)"
+8: "LRC2"
+8: "block_anti_coll_mode"
+8: "LRC3"
```

* DATA in Request Packet
    * block_anti_coll_mode: `1 byte`. Whether to use anti-collision data from emulator block 0 or not for the actived slot.

## Response Packet

```mermaid
---
title: "Response Packet"
---
packet
+8: "SOF"
+8: "LRC1"
+16: "CMD (=4015)"
+16: "STATUS"
+16: "LEN (=0)"
+8: "LRC2"
+8: "LRC3"
```

* DATA in Response Packet: None
