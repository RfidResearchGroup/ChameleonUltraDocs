# 4016: MF1_GET_WRITE_MODE

Get the write protect mode of Mifare Classic emulator.

## Request Packet

```mermaid
---
title: "Request Packet"
---
packet
+8: "SOF"
+8: "LRC1"
+16: "CMD (=4016)"
+16: "STATUS"
+16: "LEN (=0)"
+8: "LRC2"
+8: "LRC3"
```

* DATA in Request Packet: None

## Response Packet

```mermaid
---
title: "Response Packet"
---
packet
+8: "SOF"
+8: "LRC1"
+16: "CMD (=4016)"
+16: "STATUS"
+16: "LEN (=1)"
+8: "LRC2"
+8: "write_mode"
+8: "LRC3"
```

* DATA in Response Packet
    * write_mode: `1 byte`. The write protect mode of Mifare Classic emulator for the actived slot. Please refer to `nfc_tag_mf1_write_mode_t` aka `MifareClassicWriteMode` enum.
