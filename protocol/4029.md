# 4029: MF0_NTAG_RESET_AUTH_CNT

Reset AUTH counter of NTAG emulator.

* CLI: cf `hf mfu econfig --reset-auth-cnt`

```mermaid
title: "Request Packet"
---

+8: "SOF"
+8: "LRC1"
+16: "CMD (=4029)"
+16: "STATUS"
+16: "LEN (=0)"
+8: "LRC2"
+8: "LRC3"
```

* DATA in Request Packet: None
