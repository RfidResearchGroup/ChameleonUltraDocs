# 4030: MF0_NTAG_GET_PAGE_COUNT

Get page count of NTAG emulator.

## Request Packet

```mermaid
---
title: "Request Packet"
---
packet
+8: "SOF"
+8: "LRC1"
+16: "CMD (=4030)"
+16: "STATUS"
+16: "LEN (=0)"
+8: "LRC2"
+8: "LRC3"
```

* DATA in Request Packet: None

## Response Packet

```mermaid
---
title: "Response Packet"
---
packet
+8: "SOF"
+8: "LRC1"
+16: "CMD (=4030)"
+16: "STATUS"
+16: "LEN (=1)"
+8: "LRC2"
+8: "max_page_count"
+8: "LRC3"
```

* DATA in Response Packet
    * max_page_count: `1 byte`. The maximum page count of the current tag type in actived slot.
