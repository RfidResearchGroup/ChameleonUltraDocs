# 5004: VIKING_SET_EMU_ID

Set Viking ID to emulator.

## Request Packet

```mermaid
---
title: "Request Packet"
---
packet
+8: "SOF"
+8: "LRC1"
+16: "CMD (=5004)"
+16: "STATUS"
+16: "LEN (=4)"
+8: "LRC2"
+32: "viking_id"
+8: "LRC3"
```

* DATA in Request Packet
    * viking_id: `4 bytes`. The Viking ID to be emulated.

## Response Packet

```mermaid
---
title: "Response Packet"
---
packet
+8: "SOF"
+8: "LRC1"
+16: "CMD (=5004)"
+16: "STATUS"
+16: "LEN (=0)"
+8: "LRC2"
+8: "LRC3"
```

* DATA in Response Packet: None
